🛠 The Vision
The original Rapido site is a powerhouse of logistics, but I wanted to see how it would look if we pushed the Frontend Architecture to its limits. This isn't just a clone; it’s a high-fidelity UI reconstruction focused on liquid responsiveness and pixel-perfect element positioning.

🚀 The Tech Spec
This project was built to demonstrate mastery over the CSS Box Model and Fluid Design:
HTML5 Semantic Markup: Built for accessibility and SEO.
CSS3 Advanced Positioning: Uses a hybrid of position: absolute for desktop flair and flexbox for mobile stability.
Zero Dependencies: Pure, raw code. No heavy frameworks—just high performance.
Asset Synergy: High-res SVG icons and optimized .webp imagery for < 1s load times.

💎 Features & "The Flex"
The "Floating" UI: Restored the iconic Rapido overlapping image style using precise z-index layering.
Typography Refinement: Swapped standard bold weights for a sophisticated 100-300 weight hierarchy to give it a "SaaS" premium feel.
Mobile-First Engine: A custom media-query bridge that snaps the layout from "Desktop Wide" to "One-Handed Mobile" instantly.
